Prayitna — ResilienceZ disaster awareness app

AngleHack CSR Hackathon team project for disaster warning and awareness, spanning mobile, mapping, messaging, backend, and cloud components.

mobilemappingcloudhackathon

Prayitna was a team project for the ResilienceZ AngleHack CSR Hackathon in July 2024: a disaster-warning and awareness application intended to improve community resilience.

Shape

  • Android interface built with Jetpack Compose.
  • OpenStreetMap, geohashing, and Pushy Pub/Sub for location and notification flows.
  • Azure Functions, PostgreSQL, and Python across the backend and cloud boundary.

This was a cross-stack hackathon build: the useful part was making the mobile, mapping, messaging, and backend pieces meet in one practical disaster-awareness flow.
