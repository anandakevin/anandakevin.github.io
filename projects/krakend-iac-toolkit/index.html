KrakenD infrastructure-as-code toolkit

CLI and templates for API-gateway configuration across environments, with container build and publish automation.

krakendplatformopen-source

Open-source CLI that generates environment-specific KrakenD configurations from modular JSON templates, with automation to build and publish container images.

Why it exists

Editing gateway configuration by hand for each environment makes review and promotion harder. This toolkit keeps those settings in modular templates and automates image builds, based on the same approach as the gateway-delivery case study.
