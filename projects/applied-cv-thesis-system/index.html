Applied computer vision thesis system

Web-based physical-distancing detector using object detection and deep learning, later developed into a published thesis project.

computer-visiondeep-learningresearch

An undergraduate capstone that became a peer-reviewed publication: a web-based detector for physical-distancing cues, designed with Indonesian deployment constraints in mind.

Problem

Public-health messaging needed tooling that could run closer to users than a batch offline study, while keeping the scope appropriate for a research prototype.

How it worked

  • Object detection model trained and evaluated for the distancing use case.
  • Web integration — connected the detection pipeline to an interface that could run and display results in a browser.
  • Documentation and thesis narrative that later became a peer-reviewed journal article (see Credentials).
  • Reference implementation: github.com/anandakevin/bachelor-thesis-social-distance-detector

The browser interface connected model output to a usable web flow, and the thesis was later published in a peer-reviewed journal.
