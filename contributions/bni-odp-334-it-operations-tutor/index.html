BNI ODP IT Operations (via Rakamin), batch 334 — July through August 2025.

Scope

Invited for two days, extended to ten full teaching days — the heaviest tutor load in the batch. Anchor sessions across secure API development, Spring Boot, ORM, rate limiting, networking and Wireshark analysis, data pipelines, database integration, API security testing, and advanced Jenkins — often assigned one to two days before delivery.

The topics covered more than a checklist: secure coding and API security, DevSecOps, networking, databases and pipelines, automation, CI/CD, Spring Boot, ORM, rate limiting, Wireshark, API testing, and Jenkins. I used the anchor session to connect the pieces so learners could see how an operational system behaves across layers.

Sessions connected secure APIs, pipelines, databases, automation, and CI/CD to the failure paths operators had to reason about under time pressure. Participant feedback described them as insightful and technically deep, while also noting that some material was difficult to digest.
