BNI ODP IT Operations (via Rakamin), batch 343 — October through November 2025.

Engagement

Combined four full-day tutor blocks—API testing and documentation, error handling and logging, rate limiting and monitoring, secure API gateways, CI/CD and DevSecOps, latency and TCP/IP analysis with Wireshark, network troubleshooting, database integration, API versioning, and API performance—with mentoring for one of three capstone teams across 14 final-project sessions. Verified ratings were 4.95 / 5 for tutoring and 4.99 / 5 for mentoring from structured participant evaluations.

I started with a slower shared baseline, then gave the team more autonomy as the system became clearer. I helped balance Ops, backend, frontend, and observability responsibilities, while staying available for cross-layer project direction and questions between sessions.

Participant feedback repeatedly highlighted clear project direction, useful input across backend and database concerns, responsiveness between sessions, and practical guidance through blockers.

Compared with batch 334, I used clearer mental models, tighter checkpoints, and a steadier pace before giving the team more responsibility. The technical material stayed deep, but the sessions were easier to follow and apply.
