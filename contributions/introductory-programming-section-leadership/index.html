Stanford · Code in Place · Apr 2025 – Jun 2025

Section leader for Stanford Code in Place — introductory programming for a global remote cohort.

What it demonstrates

  • I can teach first principles (control flow, decomposition, debugging) without jumping straight to framework trivia.
  • Remote facilitation: keeping novices unblocked when they cannot lean over a physical keyboard.
  • Patience with uneven starting points — the same skill that later shows up in enterprise academies and capstone mentoring.

What visitors should take away

Backend and platform work is the primary track; this role is supporting evidence that explanation and mentorship scale down to beginners and up to senior engineers.
