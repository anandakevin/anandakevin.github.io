# Reviewed public media

Store only reviewed derivatives here, grouped by public record ID:

```text
public/media/<namespace>/<slug>/...
```

Keep original photos, certificates, evidence exports, and editable diagrams in
their private owners. Before adding a derivative, resize and optimize it, strip
EXIF, redact sensitive identifiers, confirm disclosure, and sanitize diagrams.
Reference derivatives from the owning Markdown record's `media` array.
